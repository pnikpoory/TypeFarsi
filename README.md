# FarsiType iPadOS PWA

نسخه آماده برای اجرای FarsiType روی iPadOS از طریق Safari و Add to Home Screen.

## اجرای آنلاین با GitHub Pages

1. یک repository جدید در GitHub بسازید.
2. فایل‌های این پوشه را داخل repository آپلود کنید:
   - `index.html`
   - `manifest.webmanifest`
   - `sw.js`
   - `icon.png`
3. از مسیر Settings → Pages، گزینه Source را روی `Deploy from a branch` بگذارید.
4. Branch را `main` و Folder را `/root` انتخاب کنید و Save بزنید.
5. بعد از چند دقیقه لینک سایت به شکل زیر فعال می‌شود:

```text
https://USERNAME.github.io/REPOSITORY/
```

6. لینک را روی iPad در Safari باز کنید و Share → Add to Home Screen را بزنید.

## نکته خروجی گرفتن روی iPadOS

برای ذخیره خروجی‌ها، از Share Sheet گزینه `Save to Files` را انتخاب کنید.


## افزودن فونت دلخواه

داخل خود برنامه دکمه «افزودن فونت از حافظه» وجود دارد. می‌توانید فایل‌های `.ttf`, `.otf`, `.woff`, `.woff2` را از Files آیپد انتخاب کنید. اگر فونت دقیق یکان، یکان‌بخ، تیتر یا نستعلیق خاصی دارید، از همین قسمت اضافه کنید تا در لیست فونت‌ها با علامت ★ نمایش داده شود.

## شخصی‌سازی رنگ تم

دکمه پالت رنگی 🎨 در نوار بالا (کنار دات‌های انتخاب تم) یک منو باز می‌کند که می‌توانید رنگ هر بخش برنامه را دستی تغییر دهید: پس‌زمینه، نوار بالا، پنل‌ها، رنگ تأکید، متن‌ها، کادرها و...

- تغییرات به‌صورت زنده اعمال می‌شوند و جداگانه برای هر تم در حافظه مرورگر ذخیره می‌شوند.
- با دکمه «🎲 رنگ تصادفی» یک پالت هماهنگ تصادفی ساخته می‌شود.
- با دکمه «بازنشانی» (یا دکمه ↺ کنار هر رنگ) می‌توانید به رنگ‌های پیش‌فرض تم برگردید.
- کنار دکمه پالت، وقتی رنگ سفارشی ذخیره شده باشد یک نقطه قرمز نمایش داده می‌شود.

## تم دفتر نقاشی 📓

تم «دفتر» (اولین دایره از چپ، کنار دکمهٔ پالت رنگی) ظاهر برنامه را به یک دفتر نقاشی/اسکچ تبدیل می‌کند:

- فضای اطراف بوم فیروزه‌ای کمرنگ با بافت اسکچ (هاشورهای محوی مثل طراحی مدادی) است.
- صفحهٔ بوم مثل دفترهای خط‌دار قدیمی است: کاغذ کرم، خط‌های آبی افقی با فاصلهٔ زیاد و خط قرمز حاشیه (هامش) سمت راست — فقط به‌عنوان پس‌زمینهٔ راهنما.
- خطوط دفتر در خروجی‌ها (PNG/JPG/PDF/AI و...) رسم **نمی‌شوند**؛ خروجی همیشه روی کاغذ کرم سادهٔ تمیز است.
- در این تم، متن‌های جدید به‌طور خودکار با رنگ آبیِ جوهر تایپ می‌شوند و با تغییر تم به رنگ قبلی برمی‌گردند.
