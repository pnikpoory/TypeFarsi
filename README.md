# FarsiType iPadOS PWA

نسخه آماده برای اجرای FarsiType روی iPadOS از طریق Safari و Add to Home Screen.

## اجرای آنلاین با GitHub Pages

1. یک repository جدید در GitHub بسازید.
2. فایل‌های این پوشه را داخل repository آپلود کنید:
   - `index.html`
   - `manifest.webmanifest`
   - `sw.js`
   - `icon.png`
3. از مسیر Settings → Pages، گزینه Source را روی `Deploy from a branch` بگذارید.
4. Branch را `main` و Folder را `/root` انتخاب کنید و Save بزنید.
5. بعد از چند دقیقه لینک سایت به شکل زیر فعال می‌شود:

```text
https://USERNAME.github.io/REPOSITORY/
```

6. لینک را روی iPad در Safari باز کنید و Share → Add to Home Screen را بزنید.

## نکته خروجی گرفتن روی iPadOS

برای ذخیره خروجی‌ها، از Share Sheet گزینه `Save to Files` را انتخاب کنید.
